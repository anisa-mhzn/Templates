# Templates in C++
This repository contains basic C++ code covering the concept of **Templates** its types(class/function template), function with multiple arguments, etc.

## Purpose
This repository is created for learning, ptacticing and understanding the basic idea of Templates in C++.

### Concept Covered
- Class Template
- Function Template
- Multiple arguments
- Function Template Overloading
- Rules for Template

## How to Run

### Compile<br>
    - g++ class_templates.cpp -o class_templates

### Run<br>
    - .\class_templates
